## 二、缺口清单（对照业界，按主题）

### 1. 漏扫 / POC 生态
| 缺口 | 业界参照 | 可行性 | 说明 |
|---|---|---|---|
| **nuclei 模板自动更新** | [nuclei-templates](https://github.com/projectdiscovery/nuclei-templates) 社区库日更 | **高** | celery 定时任务：下载模板 zip/目录同步到 nuclei 模板目录，记录版本与更新时间；POC 库页展示模板版本 |
| 自定义 nuclei 模板管理 UI | nuclei `-t` 生态 | 中 | 模板文件列表/启停/上传（复用指纹上传模式 + 路径围堵） |
| afrog 国产 POC 库引入 | [afrog](https://github.com/zan8in/afrog)（内置 CNVD/CVE PoC） | 中 | POC 格式与 NPoC/nuclei 不同，需转换器；可作为 POC 库第二来源 |
| 商业漏扫引擎（xray 等） | — | 低 | 商业授权与联动模式限制，仅适合留 webhook 输出对接 |

### 2. 空间测绘平台
| 缺口 | 可行性 | 说明 |
|---|---|---|
| Hunter/Quake/ZoomEye **查询采集任务**（按语句拉资产入扫描） | 高 | 现仅 FOFA 有 `/task_fofa/submit`；把该模式泛化成 `/task_mapping/submit`（vendor 参数化），UI 复用数据源页卡片 |
| Netlas.io（免费档 API） | 中 | 被动收集插件再+1，模式与 shodan 相同 |
| FullHunt / ZoomEye 多端点 | 低 | 覆盖与现有六家高度重叠 |

### 3. 信息收集平台
| 缺口 | 可行性 | 说明 |
|---|---|---|
| **whois 查询/注册人关联** | **高** | python-whois 本地库即可；资产详情抽屉加"WHOIS"段 + 独立检索 |
| **ICP 备案查询** | 中 | 需第三方 API（爱企查登录态已在会话池，可扩展；或商业备案 API），先定供应商 |
| GitLab 泄露监控 | 低 | GitHub 监控已有，GitLab 面向私有部署场景小 |
| Telegram/Slack 通知 | 低 | 国内渠道已全覆盖，仅出海场景需要 |

### 4. 资产侦察工具链
| 缺口 | 可行性 | 说明 |
|---|---|---|
| 代理池管理 UI | **高** | config.yaml 已有 PROXY 段，缺 UI（仿 notify_config 卡片即可），扫描出口可控 |
| 字典管理 UI（域名爆破/目录字典上传） | 中 | 引擎目录已有字典文件，缺上传/启用界面 |
| httpx/naabu 独立二进制接入 | 中 | 平台自有端口/存活实现，重叠度高，仅在特殊场景需要 |

### 5. 平台工程
| 缺口 | 可行性 | 说明 |
|---|---|---|
| **队列/worker 运行状态页** | **高** | celery inspect + rabbitmq 队列深度，看板加"运行时"卡 |
| API 响应形状统一 | 中 | 列表接口存在顶层 `{items,total}` 与 `{code,data:{items}}` 两种形状（前端已兼容），属重构债 |
| 登录 MFA / 登录审计 | 中 | 安全加固，RBAC 已有基础上可加 |
| **多工作空间** | 立项 | 大件：数据隔离+权限模型重构 |
| **分布式扫描节点** | 立项 | 大件：节点注册/任务分发/结果回传 |

## 三、本次已落地
- ✅ **Shodan 被动收集插件**（`/dns/domain/{domain}` 一次拉全量前缀）+ API Key 接入 + 探活（api-info 返回套餐档位）
- ✅ **Censys 被动收集插件**（v2 hosts/search，`dns.names` 查询 + cursor 翻页，API ID/Secret 双要素）+ 探活（/api/v2/account）
- ✅ 两者进入「数据源接入」页统一管理（掩码/保存/清除/测试），config.yaml.template 已补默认段

## 四、建议优先级
- **P1（下次直接做，均为高可行性）**：nuclei 模板自动更新、whois、代理池 UI、队列/worker 状态页
- **P2（需先定外部依赖）**：测绘查询任务泛化（Hunter/Quake/ZoomEye 语句采集）、字典管理 UI、ICP 备案（先选 API 供应商）
- **P3（需单独立项）**：多工作空间、分布式扫描节点
- **P4（重构债）**：API 响应形状统一
